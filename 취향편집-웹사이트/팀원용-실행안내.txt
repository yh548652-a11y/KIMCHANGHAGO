취향편집 웹사이트 실행 방법

1. ZIP 압축을 풀고 VS Code의 ‘파일 → 폴더 열기’로 취향편집-웹사이트 폴더를 엽니다.
2. Node.js와 npm이 설치되어 있는지 확인한 뒤, VS Code 터미널에서 npm ci를 실행합니다.
3. F5를 누르고 ‘취향편집 웹 미리보기’를 선택합니다. 개발 서버가 시작되면 VS Code 내부 브라우저에서 화면이 열립니다.
4. VS Code의 Codex 확장에 본인 계정으로 로그인하고 새 대화에서 수정할 내용을 요청합니다. src.jsx 또는 style.css를 저장하면 개발 서버가 화면에 변경을 반영합니다.

제한 모드가 표시되면 팀에서 받은 코드를 검토하고 신뢰하는 경우에만 현재 프로젝트 폴더를 신뢰하세요.
F5 실행 항목을 사용할 수 없다면 VS Code 터미널에서 npm run dev를 실행하세요. VS Code 내부 브라우저에서 터미널에 표시된 Local 주소를 열면 됩니다.
예시 데이터는 별도 서버 없이 사용할 수 있습니다. Flask 모드를 사용하려면 접속 가능한 Flask 서버 주소가 필요합니다.

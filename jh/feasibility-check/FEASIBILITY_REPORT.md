## 발견하고 수정한 문제

1. 시스템 Python에는 Flask가 없었지만 프로젝트 `.venv`에는 Flask 3.1.3이 설치되어 있었습니다. 실행 명령을 가상환경 기준으로 통일했습니다.
2. Apple 한국 Store가 음악·TV 검색 결과를 0건 반환할 수 있어 미국 Store 한 번 보조 조회를 추가했습니다.
3. Apple 영화 검색이 여러 대표 제목에서 0건이어서 한국어 Wikipedia API 보조 조회를 추가했습니다.
4. Wikipedia 검색이 감독·배우까지 포함하던 문제를 발견하여 검색 제목과 직접 일치하는 영화 문서만 표시하도록 제한했습니다.
5. 외부 출처가 Wikipedia인데 링크가 Apple로 표시되던 문제를 출처별 문구로 수정했습니다.

## 제한 및 미검증

- TMDB 토큰과 Spotify 자격 증명이 현재 PC와 저장소에 없어 두 API의 실제 인증 호출은 하지 못했습니다.
- Wikipedia는 영화 가격·평점·OTT 정보의 근거로 사용할 수 없습니다.
- Apple의 USD 가격은 미국 Store 구매 가격이며 한국 구독료가 아닙니다.
- 모든 외부 API는 지역·쿼터·정책 제한이 있으므로 무제한 연동이라고 표현할 수 없습니다.
- 팀 저장소에는 기존 Git 연습 파일만 있으므로 프로젝트 반영 전 팀 폴더와 병합 방식 합의가 필요합니다.

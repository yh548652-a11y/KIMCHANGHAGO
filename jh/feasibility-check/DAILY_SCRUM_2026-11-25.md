## 기술 타당성 결과

**조건부 가능**입니다.

- React → Flask → 외부 API → 공통 응답 → 결과 카드 흐름은 구현 및 테스트 가능
- 영화·시리즈·음악을 같은 검색 형식으로 확장 가능
- Apple API와 Wikipedia API를 이용한 실제 조회는 가능
- API 연동은 지역, 호출량, 인증, 이용약관 제한이 있으므로 `제한 없이 가능`하다고 볼 수 없음
- TMDB 토큰과 Spotify 자격 증명이 없어 두 API의 실제 인증 호출은 아직 미검증
- Wikipedia는 영화 가격·평점·OTT 정보의 근거로 사용할 수 없음
- Apple의 가격은 Store 구매 가격이며 국내 OTT 구독료가 아님

## 장애물 및 협의 사항

- 팀에서 사용할 영화·시리즈·음악의 최종 공식 출처 확정 필요
- API별 필드 차이를 공통 응답 형식으로 변환하는 규칙 합의 필요
- 가격·제공 플랫폼 정보에는 출처와 확인 시점을 함께 표시해야 함
- 비밀키는 `.env`로 관리하고 GitHub에 올리지 않음
